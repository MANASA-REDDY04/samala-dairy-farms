- ⚛️ **React** – Component-based UI development
- ⚡ **Vite** – Modern and fast development environment
- 🎨 **CSS3** – Custom responsive styling
- 📱 **Fully Responsive** – Optimized for mobile, tablet, and desktop

## 🐮 Features

- Clean and professional landing page
- Dedicated sections: About, Services, Products, Contact
- Contact methods via WhatsApp, phone, and email
- Showcase of dairy products and services
- SEO-friendly meta structure
- Lightweight and fast-loading

```bash
# Clone the repository

# Navigate into the project
cd samala-dairy-farms

# Install dependencies
npm install

# Start the development server
